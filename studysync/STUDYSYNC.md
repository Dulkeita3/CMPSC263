Steps:

1. Go to the Sign In/Get started, there you will be prompted to either enter your email and continue with sign up or you can hit log in to continue with previous credentials. The sign up option requires an email that hasn't already been used, first name, last name, number and a password that's atleast 6 characters, starts with a capital letter, has a number and a special character. The log in option features a reset password button.

2. Once Inside you'll be greeted by a dashboard that Available Sessions, Make a Session, Edit classes, Profile, and Log out. You'll be prompted to edit classes first and add classes to your cart, up to 19 credits, before being able to see avaliable study sessions or making a study session. The study sessions that are visible will only be for the classes that you're currently enrolled in, you will be allowed to filter by classes in the Avaliable Sessoins tab as well. The Make Sessions allows you to create sessions for a specific class with location and time being requirements. The time uses an api to make sure that it's in proper format. After saving the session it will be avaliable for others to see in the Avaliable Sessions and you will already be in the session.
